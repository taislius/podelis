# Contributing to Podėlis

## Pull requests

**Podėlis does not accept pull requests.** Please don't open one to get a
change merged: it won't be.

This isn't about you or your code. Reviewing pull requests takes time I
would rather spend working on Podėlis. Most pull requests today are also
written largely by AI, and if feedback on a pull request just gets passed
to a coding agent, I would rather run my own. Writing all the code myself
also keeps the licensing simple: the code is [AGPL v3.0](LICENSE) and I
hold all of its copyright.

Pull requests that are opened anyway get closed without being read. To
show what you have in mind, describe it in an issue instead: screenshots,
mock-ups and examples of the SQL or keys involved all help.

## How you can help

- **Report bugs.** Open an issue with your OS, database and version, the
  steps to reproduce it, and what you expected. `podelis doctor` output
  helps.
- **Suggest features.** Open an issue that describes the problem you want
  solved, not only the solution.
- **Reproduce other people's bugs** and add what you find to their issues.
- **Stay around** after opening an issue: watch your GitHub notifications
  so you can answer questions.
